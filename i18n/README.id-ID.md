# iNeedRouter

**iNeedRouter** adalah fork terawat dari [ineedrouter](https://github.com/salsabila2507/ineedrouter) (lisensi MIT): gateway AI multi-provider dengan satu endpoint kompatibel OpenAI/Anthropic yang merutekan trafik ke 40+ provider, lengkap dengan dashboard operator. Seluruh fitur ineedrouter dipertahankan, ditambah branding iNeed, sistem desain iNeed, dan lapisan reseller.

Dokumen bahasa Indonesia sedang disusun — sementara silakan baca [README bahasa Inggris](../README.md).

- Mulai cepat: `cp .env.example .env && npm install && npm run dev`
- Dashboard: `http://localhost:20128/dashboard`
- Endpoint: `http://localhost:20128/v1/...`
- Situs web: <https://ineed.web.id>
