# iNeedRouter

**iNeedRouter** adalah fork terawat dari [9router](https://github.com/decolua/9router) (lisensi MIT): gateway AI multi-provider dengan satu endpoint kompatibel OpenAI/Anthropic yang merutekan trafik ke 40+ provider, lengkap dengan dashboard operator privat. Seluruh fitur 9router dipertahankan, ditambah branding iNeed, sistem desain iNeed, dan kemampuan routing terpilih yang terinspirasi OmniRoute serta ZRouter.

Dokumen bahasa Indonesia sedang disusun — sementara silakan baca [README bahasa Inggris](../README.md).

- Mulai cepat: `cp .env.example .env && npm install && npm run dev`
- Dashboard: `http://localhost:20128/dashboard`
- Endpoint: `http://localhost:20128/v1/...`
- Situs web: <https://ineed.web.id>
