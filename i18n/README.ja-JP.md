# iNeedRouter

**iNeedRouter** は [ineedrouter](https://github.com/salsabila2507/ineedrouter)（MIT ライセンス）のメンテナンスされたフォークです。OpenAI/Anthropic 互換の単一エンドポイントで 40 以上のプロバイダーへトラフィックをルーティングするマルチプロバイダー AI ゲートウェイで、オペレーター向けダッシュボードを備えています。ineedrouter の全機能を保持しつつ、iNeed のブランディング・デザインシステム・再販レイヤーを追加しています。

日本語ドキュメントは準備中です。当面は[英語の README](../README.md) をご覧ください。

- クイックスタート: `cp .env.example .env && npm install && npm run dev`
- ダッシュボード: `http://localhost:20128/dashboard`
- エンドポイント: `http://localhost:20128/v1/...`
- ウェブサイト: <https://ineed.web.id>
