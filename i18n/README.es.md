# iNeedRouter

**iNeedRouter** es un fork mantenido de [ineedrouter](https://github.com/salsabila2507/ineedrouter) (licencia MIT): una pasarela de IA multi-proveedor con un único endpoint compatible con OpenAI/Anthropic que enruta el tráfico entre más de 40 proveedores, junto con un panel completo para operadores. Se conserva todo el conjunto de funciones de ineedrouter; iNeedRouter añade la marca iNeed, su sistema de diseño y una capa de reventa.

La documentación en español está en preparación; por ahora consulta el [README en inglés](../README.md).

- Inicio rápido: `cp .env.example .env && npm install && npm run dev`
- Panel: `http://localhost:20128/dashboard`
- Endpoint: `http://localhost:20128/v1/...`
- Sitio web: <https://ineed.web.id>
