# iNeedRouter

**iNeedRouter** est un fork maintenu de [ineedrouter](https://github.com/salsabila2507/ineedrouter) (licence MIT) : une passerelle IA multi-fournisseurs avec un point d'accès unique compatible OpenAI/Anthropic qui achemine le trafic vers plus de 40 fournisseurs, accompagnée d'un tableau de bord opérateur complet. L'intégralité des fonctionnalités de ineedrouter est conservée ; iNeedRouter ajoute la marque iNeed, son système de design et une couche de revente.

La documentation française est en cours de rédaction — consultez pour l'instant le [README en anglais](../README.md).

- Démarrage rapide : `cp .env.example .env && npm install && npm run dev`
- Tableau de bord : `http://localhost:20128/dashboard`
- Point d'accès : `http://localhost:20128/v1/...`
- Site web : <https://ineed.web.id>
