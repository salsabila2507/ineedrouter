# iNeedRouter

**iNeedRouter** là fork được bảo trì từ [ineedrouter](https://github.com/salsabila2507/ineedrouter) (giấy phép MIT): một cổng AI đa nhà cung cấp với một endpoint tương thích OpenAI/Anthropic duy nhất, định tuyến lưu lượng qua hơn 40 nhà cung cấp, kèm bảng điều khiển đầy đủ cho nhà vận hành. Toàn bộ tính năng của ineedrouter được giữ nguyên; iNeedRouter bổ sung thương hiệu iNeed, hệ thống thiết kế iNeed và lớp bán lại.

Tài liệu tiếng Việt đang được xây dựng — tạm thời vui lòng đọc [README tiếng Anh](../README.md).

- Bắt đầu nhanh: `cp .env.example .env && npm install && npm run dev`
- Bảng điều khiển: `http://localhost:20128/dashboard`
- Endpoint: `http://localhost:20128/v1/...`
- Trang web: <https://ineed.web.id>
