# iNeedRouter

**iNeedRouter** یک فورک نگهداری‌شده از [۹روتر](https://github.com/salsabila2507/ineedrouter) (مجوز MIT) است: یک دروازه هوش مصنوعی چند-تأمین‌کننده با یک endpoint سازگار با OpenAI/Anthropic که ترافیک را بین بیش از ۴۰ تأمین‌کننده مسیریابی می‌کند و دارای داشبورد کامل برای اپراتورهاست. تمام قابلیت‌های ۹روتر حفظ شده و iNeedRouter برندینگ iNeed، سیستم طراحی iNeed و لایه بازفروش را به آن اضافه می‌کند.

مستندات فارسی در حال تهیه است — فعلاً [README انگلیسی](../README.md) را ببینید.

- شروع سریع: `cp .env.example .env && npm install && npm run dev`
- داشبورد: `http://localhost:20128/dashboard`
- Endpoint: `http://localhost:20128/v1/...`
- وب‌سایت: <https://ineed.web.id>
