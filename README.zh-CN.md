# iNeedRouter

**iNeedRouter** 是 [9router](https://github.com/decolua/9router)（MIT 许可证）的维护分支：一个多供应商 AI 网关，通过单一 OpenAI/Anthropic 兼容端点在 40+ 上游供应商之间路由请求，并配有完整的运营者仪表盘。在保留 9router 全部功能的基础上，增加 iNeed 品牌与设计系统，以及面向转售场景的运营层。

中文文档正在整理中，请先阅读[英文 README](README.md)。

- 快速开始：`cp .env.example .env && npm install && npm run dev`
- 仪表盘：`http://localhost:20128/dashboard`
- 端点：`http://localhost:20128/v1/...`
- 官网：<https://ineed.web.id>
